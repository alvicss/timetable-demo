# 課表 CSV 轉換標準 Prompt

> 本文件提供可直接交給 AI 使用的完整 Prompt，負責將班級課表與教師課表交叉比對，輸出正式課表、班級統計與教師待確認資料。

## 使用方式

將下方 Prompt 完整貼給 AI，並在同一個對話中上傳所有班級課表與教師課表檔案。不同平台比較結果時，應使用相同檔案、相同檔案順序及相同 Prompt。

網站「提示模板」會直接擷取本文件唯一的 `text` 程式碼區塊。維護時請直接修改下方完整 Prompt，並且不要再新增第二個 `text` 程式碼區塊。

## 完整 Prompt

```text
你是一個「學校課表資料轉換與核對工具」。

請將我提供的學校課表檔案完整轉換成標準 CSV，並建立可下載的檔案。

你的工作重點依序是：

1. 不漏掉班級課表中的任何課程。
2. 不重複計算班級課表與教師課表中的同一堂課。
3. 盡可能正確補齊 teacher。
4. 使用固定規則判斷，不可憑感覺自由猜測。
5. 建立統計檔，讓我可以核對每個班級的課程列數。

━━━━━━━━━━━━━━━━━━━━
【一、來源檔案說明】
━━━━━━━━━━━━━━━━━━━━

來源檔案可能是 PDF、Excel、Word、圖片，或以上格式的組合。

檔案可能包含以下兩種課表：

1. 班級課表
以班級為單位，每一格通常顯示科目，教師姓名可能省略、縮寫或以小字顯示。

2. 教師課表
以教師為單位，每一格顯示這位教師在該時段教授的班級及科目。

班級課表與教師課表是同一批課程的不同呈現方式，不是兩批不同課程。

開始處理前，必須：

1. 檢查所有檔案。
2. 檢查所有頁面、工作表及可見區塊。
3. 不可只處理前幾頁。
4. 不可因頁面格式相似而跳過後續頁面。
5. 辨識哪些頁面是班級課表、哪些是教師課表。
6. 列出所有辨識到的班級及教師，確認沒有漏頁。

━━━━━━━━━━━━━━━━━━━━
【二、建立課程基準表】
━━━━━━━━━━━━━━━━━━━━

如果同時提供班級課表與教師課表：

1. 以班級課表建立正式課程的基準資料。
2. 教師課表主要用來補充 teacher、subject 或 location。
3. 不得將教師課表中的相同課程再次新增到正式 CSV。
4. 不得把班級課表列數與教師課表列數直接相加。
5. 不得因為找不到 teacher，就刪除班級課表中的課程。

班級課表中的每一個非空白課程格，都必須建立課程資料。

如果同一科目連續兩節：

- 必須依不同 period 拆成兩列。
- 不可合併成一列。

如果一個合併儲存格橫跨多個節次：

- 橫跨幾個節次，就拆成幾列。
- 每列使用各自的 period。

如果同一格明確包含多個班級、科目或分組課程：

- 每個班級及每個科目分別建立資料列。
- 不可將多個班級寫在同一個 class 欄位。
- 不可將兩個不同科目合併寫在同一個 subject 欄位。

以下內容不得當成課程：

- 頁面標題
- 星期或節次標題
- 上課時間說明
- 下課時間
- 午休
- 午餐或用餐時間
- 放學
- 教師名單
- 導師名單
- 備註
- 統計數字
- 說明文字
- 空白儲存格

早自習、班會、週會、自習、團體活動時間、彈性學習如果確實出現在課表格內，仍然屬於課程資料，不得省略。

━━━━━━━━━━━━━━━━━━━━
【三、只有單一版本時的處理】
━━━━━━━━━━━━━━━━━━━━

如果只有班級課表：

1. 使用班級課表建立所有課程。
2. 從表頭、導師欄、任課教師名單、備註及同班同科其他時段補充 teacher。
3. 找不到 teacher 時仍須保留課程，teacher 留空。

如果只有教師課表：

1. 使用教師課表中的班級、星期、節次及科目建立課程。
2. 同一堂課在同一位教師的課表中重複出現時，只保留一筆。
3. 明確的協同教學才依教師拆成多列。

━━━━━━━━━━━━━━━━━━━━
【四、課程唯一識別規則】
━━━━━━━━━━━━━━━━━━━━

每一筆基準課程的識別鍵為：

school + class + day + period + 標準化後的 subject

完全相同的識別鍵不得重複輸出。

只有以下情況可以使用相同識別鍵輸出多列：

1. 文件明確表示同一堂課由多位教師協同教學。
2. 同一課程明確分組，且由不同教師授課。

如果只是教師課表重複記載同一堂課，不得視為新的課程。

━━━━━━━━━━━━━━━━━━━━
【五、科目名稱標準化】
━━━━━━━━━━━━━━━━━━━━

進行 teacher 比對前，先統一科目名稱。

允許視為相同科目的明確差異包括：

- 國文＝國語文
- 英文＝英語＝英語文
- 數學科＝數學
- 體育課＝體育
- 資訊科技＝資訊
- 團體活動＝團體活動時間
- 全形與半形符號差異
- 多餘空格或換行
- 明確只是課程代碼或教師姓名的括號附註

標準名稱選擇順序：

1. 班級課表中最完整的正式名稱。
2. 整份文件中最常出現的完整名稱。
3. 無法判定時，保留班級課表原始名稱。

不可將語意不同的科目強制合併。

例如：

- 生活科技與資訊科技不可自行視為相同。
- 數學與數學演習不可自行視為相同。
- 英文與英文會話不可自行視為相同。

━━━━━━━━━━━━━━━━━━━━
【六、teacher 固定比對流程】
━━━━━━━━━━━━━━━━━━━━

每一堂課都必須依照第 1 級到第 5 級依序比對。

前一級無法確認時，才能進入下一級。

第 1 級：完全相同比對

如果教師課表中的班級、星期、節次及科目完全相同，填入該教師。

第 2 級：標準化科目比對

如果班級、星期、節次相同，而且標準化後的科目相同，填入該教師。

第 3 級：同班同時段唯一教師

如果教師課表中，相同班級、星期及節次只有一位教師，而且沒有其他資料衝突：

- 即使教師課表的科目缺漏，也填入該教師。
- 即使科目名稱有輕微差異，但不構成不同課程，也填入該教師。

第 4 級：同班同科授課規律

如果同一班級的相同科目，在其他時段都由同一位教師教授，可以推定缺漏時段也是該教師。

必須同時符合：

1. 班級相同。
2. 標準化後科目相同。
3. 至少有一筆明確的教師對應紀錄。
4. 沒有第二位教師教授該班相同科目的衝突資料。

如果同班同科出現兩位以上教師，除非文件明確表示分組或協同教學，否則不可使用這一級推定。

第 5 級：導師與特殊課程

適用於：

- 早自習
- 班會
- 週會
- 團體活動時間
- 自習
- 彈性學習
- 其他通常由導師負責的班級活動

判斷順序：

1. 文件明確記載負責教師時，填負責教師。
2. 沒有指定教師，但能確認該班導師，且沒有其他教師負責的證據時，填入導師。
3. 有證據顯示由其他教師負責時，以實際負責教師為準。
4. 完全找不到導師或負責教師時，teacher 才留空。

teacher 欄禁止填入：

- UNKNOWN
- 未知
- 無
- N/A
- 待確認
- 任課老師
- 導師
- 任何不是實際姓名的替代文字

不可自行創造來源檔案中未出現過的教師姓名。

━━━━━━━━━━━━━━━━━━━━
【七、多位教師與衝突處理】
━━━━━━━━━━━━━━━━━━━━

如果文件明確表示協同教學：

1. 每位教師各輸出一列。
2. school、class、day、period、subject、location 相同。
3. teacher 分別填入不同教師。

如果同一堂課出現兩位以上可能教師，但無法確認是否為協同教學：

1. 不可自行挑選其中一人。
2. timetable_import.csv 的 teacher 留空。
3. 將候選教師及原因寫入 teacher_review.csv。
4. 不可因為有多位候選教師，就重複新增正式課程。

如果班級課表與教師課表內容衝突：

1. 課程是否存在及課程節次，以班級課表為基準。
2. teacher 不可強行選擇。
3. 將衝突記錄到 teacher_review.csv。

━━━━━━━━━━━━━━━━━━━━
【八、教師課表獨有課程】
━━━━━━━━━━━━━━━━━━━━

如果班級課表沒有某堂課，但教師課表明確記載該課程，只有同時符合以下條件才可新增：

1. 班級名稱明確。
2. 星期明確。
3. 節次明確。
4. 科目明確。
5. 教師明確。
6. 不是教師課表中的重複資料。
7. 不是班級課表文字辨識錯誤所造成的表面差異。
8. 沒有與班級課表既有課程衝突。

新增後，必須在 timetable_summary.csv 的 teacher_only_added_count 中計數。

如果有疑問，不要直接新增，改記錄到 teacher_review.csv。

━━━━━━━━━━━━━━━━━━━━
【九、正式輸出檔案】
━━━━━━━━━━━━━━━━━━━━

請建立以下三個可下載的 UTF-8 CSV 檔案。

為了讓繁體中文在 Microsoft Excel 正常顯示，CSV 優先使用 UTF-8 with BOM 編碼。

檔案一：timetable_import.csv

第一列欄位名稱必須固定為：

school,class,day,period,subject,teacher,location

欄位規則：

- school：學校名稱，每列填寫相同名稱；真的無法辨識才留空。
- class：班級名稱，例如機械一甲、園藝一、701、八年一班。
- day：1 到 5，1=星期一、2=星期二、3=星期三、4=星期四、5=星期五。
- period：早自習可填 0；第 1 節到第 8 節填 1 到 8，其他節次依來源數字填寫。
- subject：標準化後的科目名稱。
- teacher：依固定比對流程取得的教師姓名；真的查不到才留空。
- location：來源沒有資料時留空。

每一節課一列，不得合併節次。

檔案二：timetable_summary.csv

第一列欄位名稱固定為：

school,class,base_course_count,output_row_count,teacher_filled_count,teacher_blank_count,collaboration_extra_rows,teacher_only_added_count,duplicates_removed,conflict_count,notes

欄位說明：

- base_course_count：從班級課表建立的基準課程數。
- output_row_count：該班在 timetable_import.csv 的最終列數。
- teacher_filled_count：teacher 有姓名的列數。
- teacher_blank_count：teacher 空白的列數。
- collaboration_extra_rows：因明確協同教學而增加的列數。
- teacher_only_added_count：班級課表沒有、由教師課表確認後新增的列數。
- duplicates_removed：移除的重複資料數量。
- conflict_count：仍有衝突或無法確認的課程數。
- notes：只記錄簡短異常說明，沒有異常則留空。

每個班級輸出一列。

最後再增加一列總計：

- class 固定填 TOTAL。
- 數字欄填所有班級的加總。
- TOTAL 不算入任何班級的統計。

必須符合：

teacher_filled_count + teacher_blank_count = output_row_count

正常情況下還應符合：

output_row_count
= base_course_count
+ collaboration_extra_rows
+ teacher_only_added_count

如果無法符合，必須重新檢查重複資料或統計方式。

檔案三：teacher_review.csv

第一列欄位名稱固定為：

school,class,day,period,subject,possible_teacher,reason

只有以下資料需要寫入：

1. 有兩位以上可能教師。
2. 班級課表與教師課表互相衝突。
3. 經過第 1 級到第 5 級仍無法確認教師。
4. 教師課表疑似有班級課表未出現的課程，但證據不足。
5. 科目名稱無法確認是否相同。

possible_teacher 有多位時，使用「、」分隔。

如果完全沒有需要人工確認的資料，仍須建立只有標題列的 teacher_review.csv。

━━━━━━━━━━━━━━━━━━━━
【十、CSV 格式規則】
━━━━━━━━━━━━━━━━━━━━

1. 所有檔案都必須是標準 CSV，不可輸出成 Excel 活頁簿後只修改副檔名。
2. 欄位中含逗號、雙引號或換行時，必須使用正確的 CSV 雙引號格式。
3. 不可在 CSV 中加入說明段落、Markdown 或註解。
4. 不可增加未指定的欄位。
5. 空白欄位保持空白，不可填入 UNKNOWN、N/A 或無。
6. 日期、時間或班級代碼不得被試算表自動改成其他格式。
7. timetable_import.csv 不得加入信心程度、推定原因或來源頁碼。

━━━━━━━━━━━━━━━━━━━━
【十一、固定排序】
━━━━━━━━━━━━━━━━━━━━

timetable_import.csv 依以下順序排序：

1. school
2. class
3. day
4. period
5. subject
6. teacher
7. location

timetable_summary.csv 依 class 排序，TOTAL 固定放在最後一列。

teacher_review.csv 依以下順序排序：

1. class
2. day
3. period
4. subject

相同輸入再次處理時，必須維持相同的排序方式。

━━━━━━━━━━━━━━━━━━━━
【十二、送出前強制檢查】
━━━━━━━━━━━━━━━━━━━━

建立檔案前，必須完成以下檢查：

1. 是否檢查了所有檔案、頁面及工作表？
2. 是否辨識到所有班級？
3. 每個班級的每個非空白課程格是否都有輸出？
4. 是否漏掉合併儲存格涵蓋的節次？
5. 是否錯誤合併連續兩節相同科目？
6. 是否把班級課表與教師課表重複相加？
7. 是否把標題、午休、備註或教師名單當成課程？
8. 是否因 teacher 查不到而刪除整堂課？
9. teacher 空白資料是否都完成第 1 級到第 5 級比對？
10. 是否存在可以由唯一教師或同班同科規律確認，卻仍留空的 teacher？
11. 是否將有衝突的教師姓名強行填入？
12. 是否存在非協同教學的重複資料？
13. 同一科目名稱是否已統一？
14. timetable_summary.csv 的數量是否與 timetable_import.csv 實際列數一致？
15. teacher_filled_count 加 teacher_blank_count 是否等於 output_row_count？
16. 是否出現 UNKNOWN、未知、無、N/A 或自行創造的教師姓名？
17. 三個 CSV 的欄位名稱及欄位順序是否完全正確？

如果統計數量無法對上，不得直接交付，必須先重新檢查。

━━━━━━━━━━━━━━━━━━━━
【十三、交付方式】
━━━━━━━━━━━━━━━━━━━━

優先提供以下三個可直接下載的檔案：

1. timetable_import.csv
2. timetable_summary.csv
3. teacher_review.csv

不要只在對話中展示部分範例，也不要用範例資料代替完整結果。

如果平台支援壓縮檔，可另外提供 timetable_output.zip，內容包含上述三個 CSV，但仍優先保留三個獨立 CSV。

如果平台完全無法建立可下載檔案，才可以改為貼出完整 CSV 內容，並且必須清楚分開三個檔案，不可只提供摘要或前幾列。

現在請完整處理我提供的所有課表檔案。
```

## 跨平台比較重點

先比較三個平台產生的 `timetable_summary.csv`：

1. `base_course_count` 不同：代表課表辨識、漏頁或合併儲存格拆分結果不同。
2. `base_course_count` 相同，但 `teacher_filled_count` 不同：代表教師交叉比對或推定結果不同。
3. `output_row_count` 明顯偏高：優先檢查是否把班級課表與教師課表重複相加。
4. `output_row_count` 明顯偏低：優先檢查是否漏頁、漏班級或把連續課程錯誤合併。

## 網站匯入時的 UNKNOWN 處理原則

AI 原則上不應在正式 `timetable_import.csv` 使用 `UNKNOWN`；真的查不到教師時應留空，並將待確認資訊寫入 `teacher_review.csv`。網站仍會檢查 `UNKNOWN` 類值，用來發現 AI 沒有遵守 Prompt 或資料尚未完成核對的情況。

匯入流程固定遵守以下規則：

1. 匯入時先保留原始 CSV 內容進行檢查，不先刪除或改寫資料。
2. teacher 出現 `UNKNOWN`、`UNKNOW`、`未知`、`N/A`、`NA`、`NULL`、`NONE`、`無`、`待確認` 或 `查無資料` 時，顯示明確警告。
3. 警告內容顯示原始 CSV 列號、班級、星期、節次、科目及 teacher 原值。
4. 不因 teacher 是待確認值而刪除整堂課。
5. 使用者可以取消匯入，修正 CSV 後重新匯入；也可以明確選擇「我已了解，仍然匯入」。
6. 使用者仍然匯入後，課程保留在班級課表，但待確認值不視為教師姓名，也不出現在教師查詢或教師下拉選單。

空白 teacher 與 `UNKNOWN` 類值的意義不同：

- 空白 teacher：可能是確實沒有專任教師的班會、自習或團體活動，不阻擋匯入。
- `UNKNOWN` 類值：代表資料尚未確認，匯入前一定要顯示問題明細並由使用者決定。
